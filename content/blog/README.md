# Diretório de Conteúdo do Blog

Este diretório está reservado para os posts e artigos do blog da Dendrix CRM (`dendrixcrm.com.br/blog`), previstos para a **ETAPA 9**.

A arquitetura suportará conteúdo versionado em Markdown / MDX com frontmatter padronizado (título, descrição, data, autor, tags, slug, canonical e metadados Open Graph).
